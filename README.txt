MEMORYVAULT - FAMILYVAULT

FamilyVault is integrated with the existing MemoryVault application.

DATABASE
- FamilyVault tables have already been created in production Neon.
- Migration file: migrations/001_family_accounts.sql
- Do not rerun the production migration.

EMAIL
- Mailjet handles verification and application emails.
- Configure MAILJET_API_KEY, MAILJET_SECRET_KEY,
  MAILJET_FROM_EMAIL and MAILJET_FROM_NAME in the deployment environment.

STORAGE
- Supabase Storage handles private family media.
- Signed URLs are generated by the server.

DEPLOYMENT
- Hosting: Render
- Database: Neon PostgreSQL
- Repository branch: master
